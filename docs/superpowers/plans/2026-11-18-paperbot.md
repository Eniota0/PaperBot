# PaperBot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Discord bot that daily fetches HF Daily Papers from 3 days ago (UTC), categorises and enriches them with a local Ollama model, ranks them with an author-trust bonus, posts a per-category digest, and serves per-category PDFs from a dropdown.

**Architecture:** One Python process (`python -m paperbot bot`). A pure, testable core (`hf_client`, `storage`, `llm`, `categorize`, `enrich`, `ranking`, `pipeline`, `digest`, `pdf`) driven by a thin `discord.py` layer (`bot`) that schedules runs, does catch-up, posts, and answers the menu. Pipeline is also runnable from the CLI.

**Tech Stack:** Python ≥ 3.11, discord.py ≥ 2.4, httpx, pydantic v2, PyYAML, python-dotenv, fpdf2, SQLite (stdlib `sqlite3`); tests with pytest, pytest-asyncio, respx.

**Spec:** `docs/superpowers/specs/2026-11-18-paperbot-design.md`

## Global Constraints

- Delay: target date D = today(UTC) − `delay_days` (default **3**). All date logic in UTC.
- All user-facing output in **English**.
- Must run on **Windows** (owner) and Linux; no dependencies needing system libraries; use `pathlib`, no shell-specific code.
- Defaults (all in `config.yaml`): schedule `08:00` UTC, `catchup_max_days` 7, `backfill_days` 90, `top_n` 10, `trust_vote_threshold` 50, `trust_cap` 5, `trust_weight` 0.05, Ollama `http://localhost:11434`, model `qwen2.5:7b-instruct`.
- Default categories (name · emoji): LLMs & Reasoning 🧠 · Agents 🤖 · Multimodal / Vision-Language 🖼️ · Computer Vision 👁️ · Image & Video Generation 🎨 · Audio & Speech 🔊 · Robotics & Embodied AI 🦾 · Efficiency & Inference ⚡ · Training & Data 📊 · Safety & Alignment 🛡️ · Benchmarks & Evaluation 📏 · Other 📦. `Other` is mandatory.
- Trust only from authors linked to an HF user; no name matching.
- Secrets only in `.env` (`DISCORD_TOKEN`); `config.yaml`, `.env`, `data/` git-ignored.
- Pipeline (HTTP/LLM) must never run on the Discord event loop: call via `asyncio.to_thread`.
- Layout: `src/paperbot/…`, tests in `tests/`, runtime data in `data/` (DB `data/paperbot.db`, PDFs `data/pdf/`, logs `data/logs/`).

## Review Focus

1. HF items with missing/null fields (no `user` on an author, no `ai_keywords`/`ai_summary`, null abstract) must parse, not crash → test in Task 3.
2. A paper re-featured on a later date must keep its original date (upsert must not move it) → test in Task 4.
3. LLM category answers with different case/whitespace (`" llms & reasoning "`) must match the right category → test in Task 6.
4. Huge days (long titles, 40 papers in one category) must stay within Discord limits → test in Task 9.
5. Author names with non-Latin characters (`Zoë Łukasz 王伟`) must render in the PDF → test in Task 10.

### Task 8: Pipeline and CLI

**Files:**
- Create: `src/paperbot/pipeline.py`, `src/paperbot/__main__.py`
- Test: `tests/test_pipeline.py`

**Interfaces:**
- Consumes: `Settings`, `Storage`, `HFClient`, `LLMProvider`, `categorize`, `enrich`, `rank_day`, `author_trust`, `HFUnavailable`, `LLMUnavailable`.
- Produces:
  - `class Pipeline(settings: Settings, storage: Storage, hf: HFClient, llm: LLMProvider)`
    - `run(d: date, force: bool = False) -> list[CategoryGroup]` — fetch + upsert (votes refreshed every run); categorise papers with `category is None` (all if `force`); enrich papers with `enrichment is None` (all if `force`); `mark_date_done`; return `ranked(d)`. `HFUnavailable`/`LLMUnavailable` propagate and the date is **not** marked done. Logs progress (`categorised 12/34`).
    - `ranked(d: date) -> list[CategoryGroup]` — from storage only; `trust_of(u) = author_trust(storage.author_upvotes_before(u, d), …)`.
    - `backfill(days: int, today: date) -> int` — fetch + upsert metadata for `today − delay_days − days … today − delay_days − 1`, no LLM calls; skips dates whose fetch fails (logged); returns number of papers stored.
  - `build_pipeline(settings: Settings) -> Pipeline` (wires real `Storage`, `HFClient`, `OllamaProvider`).
  - CLI `python -m paperbot`: `bot` (Task 11), `run --date YYYY-MM-DD [--force]` (prints ranked groups: `category / rank. ▲votes title`), `backfill [--days N]` (default `settings.backfill_days`). Global `--config PATH`. Calls `setup_logging`.
